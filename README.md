# AetherCloud 🌩️

> 🚧 **Work in Progress (WIP):** This project is currently under active development. Some features and bug fixes are pending.

**AetherCloud** is a high-performance, portfolio-grade web application designed to simulate distributed cloud node clusters and infrastructure routing in real-time WebGL. Built from the ground up to showcase advanced full-stack capabilities, modern UI/UX design, and secure integrations.

---

## 🚀 Core Tech Stack

* **Frontend Framework:** [Next.js](https://nextjs.org/) (App Router, [TypeScript](https://www.typescriptlang.org/))
* **3D Graphics & Animation:** Three.js, React Three Fiber (R3F), Drei, Framer Motion
* **Styling & Design:** [Tailwind CSS](https://tailwindcss.com/) (Cyberpunk dark-mode / glassmorphism aesthetic)
* **Payments & Security:** Paystack SDK with secure server-side transaction verification (`/api/verify-payment`)

---

## ✨ Key Features

* **Retro-Futuristic Boot Sequence:** Immersive terminal initialization simulation on first load.
* **Interactive WebGL Viewport:** Custom-rigged 3D rotating wireframe cloud core with dynamic node orbit rings.
* **Secure Monetization Flow:** Zero-trust client-server transaction verification ensuring no payment spoofing.
* **Developer Profile Integration:** Fully integrated showcase details for Lead Full Stack & Cloud Engineer portfolios.

## 🚀 Getting Started Locally

Follow these steps to run AetherCloud on your local machine:

```bash
# 1. Clone the repository
git clone [https://github.com/Darnee297858/aethercloud.git](https://github.com/Darnee297858/aethercloud.git)

# 2. Navigate into the directory
cd aethercloud

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
